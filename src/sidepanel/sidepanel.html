Why is a Mac Helper required?

Our current ChatGPT sign-in uses OpenAI's local authorization flow, and browser-only sign-in is not available for this extension yet. The Helper runs locally on your Mac to complete the sign-in and store the credential securely. Install it once.

Why the Helper?

The Helper is part of this project — not an OpenAI product. It is a small program that runs on this Mac, completes the sign-in through OpenAI's local authorization flow, and keeps the resulting credential in a file that only it can read. Your browser never sees the credential, and neither does this extension.

Install it: the macOS installer is not published yet, so there is nothing to download today. View Helper releases — once the installer is there, it installs the Helper and starts it in the background.

If you already have the project folder, you can start the Helper yourself with:

node helper/siwc-helper.js

That needs Node.js 20 or later. Nothing else has to be installed first — the Helper has no dependencies.

Whether your ChatGPT plan can be used this way depends on your account, and signing in opens a normal browser tab at openai.com. If it turns out not to work for you, or you would rather not use it, switch to Your own API key above — that method needs nothing installed and works with any OpenAI-compatible provider.

Where do I find these details?

They come from the AI service you already have an account with — this extension does not provide AI by itself, and does not recommend one provider over another.

  • API Base URL — in your provider's developer or API documentation. It looks like a web address, usually ending in /v1.
  • API Key — in your provider's dashboard, under API keys. Copy the whole key; it does not have to start with any particular letters.
  • Model ID — the exact name of the model you want to use, as your provider writes it.

You can change any of this later from the ⚙ button at the top right.

Why the Helper?

The Helper is part of this project — not an OpenAI product. It is a small program that runs on this Mac and holds your ChatGPT sign-in. OpenAI's sign-in for open-source apps only accepts a callback to 127.0.0.1, which a browser extension cannot provide, so this extension asks the Helper to do it.

Install it: the macOS installer is not published yet, so there is nothing to download today. View Helper releases — once it is there, it installs the Helper and starts it in the background. Otherwise, start it with:

node helper/siwc-helper.js

Send a test request spends a little of your plan's allowance. Test Connection below does not — it only checks that the helper is running, that you are signed in, and that the model is one your account has.
